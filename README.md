# stock_prediction
This project aims to predict stock market trends using various machine learning models and time series analysis techniques. It uses historical stock data to forecast future prices, helping investors make informed decisions.
<h2>Feature</h2>

✅ Historical data retrieval from Yahoo Finance or other sources

📊 Data visualization with candlestick charts and trend lines

🤖 ML models: Linear Regression.

📈 Predict closing prices or trend (up/down)

🧼 Data preprocessing and feature engineering

🌐 Web interface with Flask or Streamlit


<h2>Tech Used</h2>
Languages: Python

Libraries:

pandas, numpy – data handling

matplotlib, seaborn, plotly – visualization

scikit-learn – traditional ML models

tensorflow/keras – deep learning (e.g., LSTM)

yfinance  – stock data


Tools : Flask/Streamlit (for web UI),
